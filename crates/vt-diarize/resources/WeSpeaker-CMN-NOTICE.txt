The acquired ONNX has no feature_normalize_type metadata entry or input CMN
node. Sherpa-onnx 2.0.1 uses the explicit global-mean metadata value to select
its native feature normalization. This derivative makes that choice explicit
under a distinct model/preprocessing identity. It does not apply an inferred
ERes2Net rule or claim full WeSpeaker reference parity: native sample windows
and other implementation details remain independently measurable.
